健康数据在你的设备上读取和处理。无需注册账户，不向开发者服务器上传健康记录。支持来信与网站托管日志另行说明如下。

01 适用范围与开发者

本政策适用于“健身人 / Gym Watch”的 iPhone App、Apple Watch App、表盘组件以及本支持网站。应用由本项目开发者 Winston-Tao1 维护。本文说明当前 1.0 版本的数据处理方式；Apple 和 GitHub 各自的服务还受其自身隐私政策约束。

02 经你授权读取的健康数据

App 使用 Apple HealthKit，在获得相应授权后读取体能训练记录（包括时间、时长及可用的训练活动消耗）、心率、活动能量、步数和睡眠记录，用于健康概览、趋势与消耗统计。App 申请的是读取权限，不会向 Apple 健康写入记录。你可以只授权部分数据；相关功能可能因此显示空白或不完整信息。

03 你在 App 中设置的信息

健身模式、健身人格选择、训练计划、热量与步数目标、目标体重、语言及外观偏好保存在设备本地。目标体重是你填写的目标，不是 App 从健康库自动读取的实际体重。人格选择和计划关联统计在设备上完成；App 不会为了这些功能把健康信息发送给云端 AI 服务。

04 处理、存储与配对设备同步

iPhone 与 Apple Watch 分别读取本机可用的健康记录，生成统计和显示缓存。App 使用本地存储及 App Group 在 App 与组件之间共享必要数据，并通过 Apple WatchConnectivity 在配对的手机和手表之间交换设置、计划及健康数据摘要。组件读取缓存；更新时机由系统调度。当前版本不要求创建账户，也没有用于接收用户健康记录的开发者服务器。设备系统备份的行为由 Apple 服务和你的备份设置决定。

05 统计的含义

部位消耗依据你设置的训练日安排，关联体能训练或全天活动消耗，不是对实际肌肉训练部位的自动识别。最近训练、今日消耗与最近睡眠采用不同的时间范围。网站及组件选择界面可以使用明确标注的示例数据，示例并非你的实际健康记录。App 提供健身信息展示，不用于诊断或治疗。

06 广告、追踪与第三方分析

当前 App 不集成广告、跨 App 追踪或第三方使用行为分析 SDK。我们不将通过 HealthKit 获得的数据出售、用于广告投放或交给广告商。当前网站不安装广告或访问分析脚本，不使用营销 Cookie，也不嵌入第三方视频播放器。

07 网站托管与访问日志

本网站由 GitHub Pages 托管。根据 GitHub 的说明，访问 GitHub Pages 时，GitHub 会为安全目的记录并保存访客 IP 地址；网络服务还可能处理提供页面所需的技术请求信息。这与 App 的本地健康数据处理是不同的。有关 GitHub 的处理方式，请参阅其隐私声明。本站的图片、样式和脚本随网站一同提供。

08 主动联系支持

如果你通过支持邮箱联系我们，我们会收到你主动发送的邮箱地址、消息及附件，用于回复与排查问题；邮件还由相应邮件服务商处理。如果通过 GitHub Issues 提交问题，内容和 GitHub 用户身份会公开，并由 GitHub 处理。请只提供解决问题必需的信息，不要公开完整健康记录或账户凭据。支持来信在处理请求所需的期间内保留；你可以联系开发者申请删除我们持有的支持通信，适用法律要求保留的情况除外。

09 你的选择与删除

你可以在 Apple 的健康隐私设置中撤销读取权限，或在 App 中修改自己的目标、计划和偏好。撤销健康权限不会自动清除已生成的本地缓存；若要移除 App 数据，需要在 iPhone 和 Apple Watch 上分别删除 App（不是仅卸载并保留数据），并按需管理系统备份。配对设备、组件和系统备份可能有各自的数据副本，因此不承诺撤权或单端删除后立即删除所有副本。App 不会删除 Apple 健康中原有的记录。关于支持通信的访问或删除，可通过下方邮箱联系。

10 儿童与数据安全

本产品不面向 13 岁以下儿童提供定向服务，也不主动要求儿童提交个人信息。如果你认为儿童通过支持渠道发送了个人信息，请联系我们处理。我们尽量减少需要处理的信息，并依赖 iOS、watchOS 和 Apple 提供的权限与设备存储保护。没有任何设备或传输方式能够保证绝对安全。

11 政策更新与联系

功能或数据处理方式发生变化时，我们会更新本页面及生效日期。对本政策、数据访问或支持通信删除有疑问，请联系开发者。
