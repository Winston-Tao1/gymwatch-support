# Visual assets

App UI screenshots and character illustrations come from the Gym Watch project. iPhone goal screenshots show **造肌者 / Builder**. Data-page screenshots use an isolated temporary simulator build with explicitly marked sample readings (48 minutes, 132 bpm, 386 kcal, 8 hours sleep); the production application source and health database were not changed.

Device images are presentation assets, not product specifications. Watch UI screenshots are independently layered using HTML and CSS, so their text is not generated by AI. iPhone presentation uses complete, unmodified lit-screen Device Hub captures, with the native hardware and UI in one image.

- `iphone-full-goals-zh/en.webp` and `iphone-full-data-zh/en.webp`: complete lit-screen iPhone 18 Pro Max Device Hub captures, stored losslessly. A browser SVG mask follows the native phone silhouette to hide the surrounding window. Hardware, bezel, Dynamic Island, and app pixels stay together exactly as captured; no AI-generated phone frame or reconstructed UI is used.
- `simulator-ultra4.webp`: frontal Apple Watch Ultra 4 hardware from Xcode Device Hub, extracted with background removal.
- `apple-ultra4.webp`: adapted from Apple's complete natural titanium / Ocean Band product render on [Apple's Watch store](https://www.apple.com/shop/buy-watch/apple-watch-ultra). Background and original display content removed for app presentation.
- `apple-series12.webp`: adapted from Apple's [Series 12 Newsroom](https://www.apple.com/newsroom/2026/09/introducing-apple-watch-series-12-with-the-all-new-health-sensing-system/) black aluminum / Burgundy Plaid Sport Loop product image. Background and original display content removed for app presentation. The same woven loop band was recolored light blue for the website; this is a presentation edit, not an assertion of an official color configuration.

The angled Ultra screenshot uses a dedicated SVG screen mask fitted to the product render, including its asymmetric corner contours.

Product cutouts were processed with imagegen. No Apple Design Resources DMG was mounted or used; no Lumy images are distributed. Lumy's website was a layout reference.

Apple product imagery belongs to Apple. App imagery and code belong to the app developer. This project does not claim Apple's endorsement.

The Series 12 hero face layers two native Gym Watch component renders over its simulator face screenshot: `watch-cyber-level1.webp` is the existing green Level I Cyber Tech render; `watch-cut-mode.webp` is exported from the current `GoalModeCircularComplication` SwiftUI view in a Watch simulator. These are real app artwork, composed in HTML/CSS rather than AI-generated UI.
